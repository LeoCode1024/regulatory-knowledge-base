# 知识库重塑循环记录

## 循环机制

- A 子Agent：重塑知识库。
- B 子Agent：按《财险监管知识库衡量标准》评分。
- C 子Agent：根据 B 的评分指出问题和修改意见。
- 主Agent：负责协调循环、运行校验、管理 Git 版本和判断是否进入下一轮。

## Git 版本规则

1. 每一轮 A 开始前，记录上一轮有效分数和当前分支状态。
2. A 完成后，先运行校验，再交给 B 复评。
3. 如果 B 的新评分高于上一轮有效分数，则保留该轮修改，更新版本号并记录为新有效版本。
4. 如果 B 的新评分低于或等于上一轮有效分数，则放弃该轮修改，回到上一轮有效版本。
5. 当 B 的评分达到 95 分及以上，目标完成。
