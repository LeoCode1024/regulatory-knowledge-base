# 反洗钱客户尽调和可疑交易流程

## 一、监管结论

反洗钱流程应从客户准入开始，而不是从可疑交易报告才开始。经办时要把客户尽职调查、风险评级、持续识别、资料保存、可疑交易监测、限制或拒绝交易、报告和整改问责串成闭环。

## 三、办理流程

### 1. 客户准入和尽职调查

- 建立业务关系或办理高风险业务前，应识别客户身份、受益所有人、交易目的和资金来源。
- 客户拒绝配合、身份无法确认或风险超出控制能力的，应限制或拒绝办理业务，必要时终止关系并提交可疑交易报告。
- 不得因销售压力跳过客户尽调，也不得对高风险客户采取简化措施。

依据：[[wiki/来源/01_法律与行政法规/中华人民共和国反洗钱法(2024修订)#第二十九条|《反洗钱法(2024修订)》第二十九条]]、[[wiki/来源/13_反洗钱/金融机构客户尽职调查和客户身份资料及交易记录保存管理办法#第三十一条|《客户尽职调查和资料保存办法》第三十一条]]、[[wiki/来源/13_反洗钱/金融机构客户尽职调查和客户身份资料及交易记录保存管理办法#第三十二条|第三十二条]]。

### 2. 风险评级和持续识别

- 反洗钱牵头部门应根据客户身份、地域、业务、渠道、交易特征和历史行为评定风险等级。
- 客户信息、受益所有人、交易模式或风险事件发生变化时，应重新识别并更新风险等级。
- 对高风险客户应加强尽调、提高复核层级和监测频率。

依据：[[wiki/来源/13_反洗钱/金融机构反洗钱和反恐怖融资监督管理办法#第八条|《金融机构反洗钱和反恐怖融资监督管理办法》第八条]]、[[wiki/来源/01_法律与行政法规/中华人民共和国反洗钱法(2024修订)#第三十八条|《反洗钱法(2024修订)》第三十八条]]。

### 3. 可疑交易分析和报告

- 系统预警后，业务部门应补充交易背景，反洗钱岗位应形成分析结论，说明排除或报告理由。
- 决定报告的，应按监管要求报送可疑交易报告，并留存报送回执和后续补充材料。
- 调查可疑交易活动时，应核验调查人员人数、证件和调查通知书；不符合要求的，机构有权拒绝调查。

依据：[[wiki/来源/01_法律与行政法规/中华人民共和国反洗钱法(2024修订)#第六条|《反洗钱法(2024修订)》第六条]]、[[wiki/来源/01_法律与行政法规/中华人民共和国反洗钱法(2024修订)#第三十条|第三十条]]、[[wiki/来源/01_法律与行政法规/中华人民共和国反洗钱法(2024修订)#第四十三条|第四十三条]]。

### 4. 资料保存和整改复盘

- 客户身份资料、交易记录、尽调材料、风险评级和可疑交易分析记录应按制度保存。
- 监管检查、自查或审计发现问题时，应按客户、产品、渠道、系统规则和人员责任分解整改。
- 对未按规定开展客户尽调、资料保存或可疑交易报告的，应同步评估行政处罚和内部问责风险。

依据：[[wiki/来源/01_法律与行政法规/中华人民共和国反洗钱法(2024修订)#第三十八条|《反洗钱法(2024修订)》第三十八条]]、[[wiki/来源/01_法律与行政法规/中华人民共和国反洗钱法(2024修订)#第五十三条|第五十三条]]。

## 四、材料和留痕

| 材料类型 | 留痕内容 |
| --- | --- |
| 客户尽调 | 身份资料、受益所有人识别、风险评级、资金来源说明 |
| 监测分析 | 系统预警、人工分析、排除理由、升级审批 |
| 报告材料 | 可疑交易报告、报送回执、补充资料、监管沟通 |
| 整改材料 | 问题台账、系统规则调整、培训记录、问责和复核 |
