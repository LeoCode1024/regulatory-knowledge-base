# 声誉事件处置流程

## 一、监管结论

声誉事件应按“监测预警、分级研判、报告决策、回应处置、复盘整改”办理。处置重点不是单次舆情回应，而是董事会和高级管理层职责、跨部门事实核验、客户权益保护、信息发布口径和整改问责的完整留痕。

## 三、办理流程

### 1. 监测预警

- 对媒体报道、社交平台、客户投诉、监管通报、重大案件、数据安全事件和销售误导等线索进行日常监测。
- 判断是否可能引发集中投诉、负面传播、监管关注或客户权益受损。
- 对高敏感事项应同步通知业务负责人、合规法务和声誉风险牵头部门。

依据：[[wiki/来源/14_行政处罚与市场行为/银行保险机构声誉风险管理办法(试行)#第七条|《声誉风险管理办法》第七条]]。

### 2. 分级研判和事实核验

- 声誉风险牵头部门组织业务、法务、合规、消保、客服核对事实、责任边界、客户影响和监管风险。
- 分级应考虑传播范围、客户数量、监管关注、违法违规可能性、涉众风险和处置难度。
- 未核实前不得对外发布结论性表述；需要临时回应的，应说明已启动核查和客户服务安排。

依据：[[wiki/来源/14_行政处罚与市场行为/银行保险机构声誉风险管理办法(试行)#第十一条|《声誉风险管理办法》第十一条]]。

### 3. 报告决策和对外回应

- 达到重大声誉事件或突发事件标准的，应按内部授权向高级管理层报告，并按监管要求报送。
- 对外回应应统一口径，避免夸大、隐瞒、甩责或发布未经核实的信息。
- 涉及客户权益的，应同步安排咨询、投诉处理、补救措施和后续反馈。

依据：[[wiki/来源/14_行政处罚与市场行为/银行保险机构应对突发事件金融服务管理办法#第二十六条|《应对突发事件金融服务管理办法》第二十六条]]、[[wiki/来源/02_公司治理与机构管理/金融机构合规管理办法#第十二条|《金融机构合规管理办法》第十二条]]。

### 4. 复盘整改

- 事件结束后应复盘触发原因、响应速度、客户影响、信息发布、监管沟通和制度缺口。
- 对销售、理赔、投诉、数据安全、外包或人员管理问题，应形成整改台账并跟踪完成。
- 重大问题应纳入内审、合规检查或问责程序。

依据：[[wiki/来源/14_行政处罚与市场行为/银行保险机构声誉风险管理办法(试行)#第十五条|《声誉风险管理办法》第十五条]]。

## 四、材料和留痕

| 材料类型 | 留痕内容 |
| --- | --- |
| 监测预警 | 舆情截图、投诉汇总、预警单、事实线索 |
| 研判决策 | 分级意见、会议纪要、法律合规意见、管理层批示 |
| 处置回应 | 对外口径、客户沟通记录、监管报告、媒体回应 |
| 复盘整改 | 复盘报告、整改台账、制度修订、问责和培训 |
