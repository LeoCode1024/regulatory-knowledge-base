# 分支机构设立变更退出流程

## 一、监管结论

分支机构设立、变更和退出是行政许可与经营管控事项，不是单纯工商或行政事务。实务中应把机构规划、准入条件、申请材料、筹建期限、开业验收、许可证管理、变更报告和退出处置放在同一台账中管理，重点控制材料真实性、负责人资格、偿付能力和既有分支机构处罚情况。

## 三、办理流程

### 1. 设立前规划和准入判断

- 机构管理部门先判断拟设机构层级、区域、业务必要性、资源投入和对偿付能力、准备金、内控管控的影响。
- 申请人及同层级既有分支机构存在重大处罚、负责人缺位、临时负责人超期、营业场所频繁变更等情形的，应先核对是否构成禁止或限制设立事项。
- 规划结论应提交管理层或董事会授权层级审议，形成是否申请、申请层级、筹建负责人和资源投入安排。

依据：[[wiki/来源/02_公司治理与机构管理/保险公司分支机构市场准入管理办法#第十三条|《保险公司分支机构市场准入管理办法》第十三条]]、[[wiki/来源/02_公司治理与机构管理/保险公司分支机构市场准入管理办法#第十四条|第十四条]]、[[wiki/来源/02_公司治理与机构管理/保险公司分支机构市场准入管理办法#第十五条|第十五条]]。

### 2. 申请材料准备和报送

- 申请材料应覆盖拟设机构管控职责、处罚或立案调查情况、同层级机构运营情况、准备金监管符合性、筹建负责人简历等内容。
- 财务、人力、信息科技、合规部门分别对资本资源、人员资格、系统条件、材料真实性出具核验意见。
- 报送前应建立材料版本清单，确保申请文件、附件、承诺和内部审议记录一致。

依据：[[wiki/来源/02_公司治理与机构管理/保险公司分支机构市场准入管理办法#第十七条|《保险公司分支机构市场准入管理办法》第十七条]]。

### 3. 筹建和开业验收

- 获准筹建后，筹建组应在筹建期限内完成职场、人员、系统、制度、内控和客户服务准备，不得在筹建期间开展保险经营活动。
- 筹建期限届满前无法完成的，应按规则办理延期或重新评估设立必要性。
- 开业申请前，应核对是否仍满足准入条件，是否出现处罚、负责人资格、场所、系统或偿付能力变化。

依据：[[wiki/来源/02_公司治理与机构管理/保险公司分支机构市场准入管理办法#第十九条|《保险公司分支机构市场准入管理办法》第十九条]]、[[wiki/来源/02_公司治理与机构管理/保险公司分支机构市场准入管理办法#第二十一条|第二十一条]]、[[wiki/来源/02_公司治理与机构管理/保险公司分支机构市场准入管理办法#第二十二条|第二十二条]]。

### 4. 许可证、公示和变更管理

- 开业后应及时办理许可证和营业执照相关手续，并在营业场所显著位置公示许可证原件。
- 机构名称、营业场所、负责人、业务范围、撤销等事项发生变化时，应先判断是否需行政许可、报告或许可证换领。
- 对客户服务、保单管理、投诉处理和档案承接有影响的变更，应同步制定客户告知和风险处置方案。

依据：[[wiki/来源/02_公司治理与机构管理/银行保险机构许可证管理办法#第十三条|《银行保险机构许可证管理办法》第十三条]]、[[wiki/来源/01_法律与行政法规/中华人民共和国保险法(2015修正)#第八十四条|《保险法(2015修正)》第八十四条]]。

### 5. 退出和撤销

- 撤销或退出分支机构前，应清点保单、客户、投诉、人员、资产、档案和监管事项，明确承接机构。
- 涉及许可证注销、公告、客户权益或监管审批的，应按监管路径完成后再办理工商和内部系统关闭。
- 退出后保留客户告知、业务承接、许可证处理、档案移交、监管回执和风险复盘材料。

依据：[[wiki/来源/02_公司治理与机构管理/保险公司分支机构市场准入管理办法#第三十二条|《保险公司分支机构市场准入管理办法》第三十二条]]。

## 四、材料和留痕

| 材料类型 | 留痕内容 |
| --- | --- |
| 规划材料 | 可行性研究、机构规划、偿付能力和资源投入测算 |
| 申请材料 | 申请文件、管控说明、处罚调查说明、筹建负责人材料 |
| 筹建材料 | 职场、系统、人员、制度、内控和开业验收底稿 |
| 许可证材料 | 许可证、营业执照、公示照片、换领和注销记录 |
| 退出材料 | 客户承接、档案移交、公告、监管回执、风险复盘 |

## 五、风险后果

- 未经批准设立分支机构、超范围经营或材料虚假，可能触发保险法下的行政处罚。依据：[[wiki/来源/01_法律与行政法规/中华人民共和国保险法(2015修正)#第一百六十四条|《保险法(2015修正)》第一百六十四条]]、[[wiki/来源/01_法律与行政法规/中华人民共和国保险法(2015修正)#第一百七十条|第一百七十条]]。
- 筹建期间开展经营、逾期未申请开业或许可证未按规定公示，会影响后续准入和监管评价。
